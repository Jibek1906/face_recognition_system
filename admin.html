Настройки Системы Распознавания

ℹ️ Как работают настройки?

Любые изменения на этой странице применяются мгновенно — вам не нужно перезапускать сервер. Значения автоматически сохраняются и сразу начинают использоваться для распознавания лиц и трекинга посетителей. Если что-то пойдет не так, вы всегда можете нажать кнопку «Сброс по умолчанию».

Параметры ядра

👤 Добавление новых людей и Порог схожести

Эти параметры контролируют, когда система решает создать нового клиента, а когда объединить его с уже существующим. Увеличение порогов снижает количество ошибочных дубликатов, но требует лучшего качества лиц в кадре.

Чем выше (напр. 0.65), тем строже система сопоставляет лица.
Мин. уверенность (0..1) снимка лица, необходимая для создания профиля.
Сколько кадров подряд человек должен быть виден для создания базы.
Игнорировать снимки профиля/уха.
Сколько снимков анфас нужно накопить до создания лица.
Сколько успешных распознаваний нужно для подтверждения личности.

⚡ Оптимизация детектора и трекинга

Настройте производительность. Пропуск кадров (N) экономит ресурсы сервера. Ограничение минимального размера лиц отсекает ложные срабатывания на фоне.

Когда включено, система сама реже обрабатывает кадры в покое и чаще - сразу после движения/визита. Пока включено, поле "Распознавать каждые N кадров" ниже не действует - частоту задаёт event-gating.
Порог уверенности детектора (YOLO). По умолчанию 0.45.
Например, 3 — значит проверять только каждый 3-й кадр (ускоряет работу).
⚠️ Сейчас не действует - включён умный пропуск кадров выше
Лица меньше этого размера (в пикселях) будут игнорироваться.
Мин. ширина рамки лица для отправки на нейросеть (ReID).
Интервал помещения лиц в очередь нейросети. Увеличьте для снижения нагрузки.
